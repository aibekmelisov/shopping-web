# ТЗ: Shopping List (веб)

Стек: Python 3, Flask (сервер и REST API), SQLite (база), HTML, CSS и JavaScript (страница).

## Функции

1. Создать список покупок, переименовать его и удалить.
2. Добавить товар: название, количество (целое число больше нуля) и цену (необязательно).
3. Отметить товар купленным и снять отметку.
4. Удалить товар.
5. Одинаковые товары в одном списке (то же название без учёта регистра) объединяются: количество и цена складываются.
6. Внизу списка итоги: всего, куплено, осталось.
7. Ошибки ввода показываются на странице: пустое название, количество не больше нуля, отрицательная цена.
8. Данные хранятся в SQLite и остаются после перезапуска сервера.
